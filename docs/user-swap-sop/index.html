阅读指引

本手册以「换电用户端」的界面设计图为底稿，按真实操作路径逐屏说明入口、操作步骤、提示与结果。

适用读者

  • 换电用户：按章节顺序操作，遇到不熟悉的页面直接看对应截图。
  • 门店 / 一线服务人员：按图指导用户完成注册、购套餐、扫码换电与还电。
  • 客服：按图定位用户所在环节，快速判断问题出在哪一步。

术语与口径

术语含义
站点地图上可换电 / 可还电的位置，一个站点可放置多个换电柜。
换电柜 / 柜机存放电池的柜体，柜号如 A01、A03；一个站点可放多个换电柜。
满电仓 / 空仓存放满电电池的仓位 / 可放入旧电池的空仓位；站点卡片上的两个数字即两类仓位数量。
换电 / 借电 / 还电换电＝放旧取新（4 步）；借电＝只取满电电池（2 步）；还电＝只归还电池（2 步）。
换电区域用户选择的运营商服务区域（国家 → 省份 → 城市 → 运营商），未设置时无法购买套餐与扫码使用。
押金按运营商配置的换电押金，未缴纳（或未免押）无法使用换电与购买套餐。

截图取自「用户端 · 简体中文」设计稿：启动页品牌为 Sunlight Eco-Tech、登录页与站点照片为雅迪标识，属设计稿示意。截图中的用户昵称、站点名、柜号、订单号、金额均为演示数据，不代表线上真实值。

第 1 章 登录与注册

三种登录方式与账号注册。App 冷启动进入租车系统，进入换电系统的方式见第 12 章。

1.1 登录方式

登录页由首页横幅「您还未登录，点我快速登录」、套餐页「去登录」、首页「扫码换电」或任意需要登录的操作唤起（图 1）。左上角返回键可关闭登录页回到原页面；右上角可切换语言。

页面底部提供三个入口切换登录方式：账号登录（默认）、手机号登录、邮箱登录；手机号与邮箱内部还能再切「验证码登录 / 密码登录」。密码框右侧的眼睛图标可查看已输入的密码，账号框右侧的清除按钮可一键清空重填。

按页面提示填写对应内容即可：手机号登录需先选左侧国际区号，验证码登录点「获取验证码」并等待短信；下方「我已阅读并同意《用户隐私政策》」需勾选后才能点登录。用未注册的手机号 / 邮箱验证码登录会自动创建账号，是最省事的注册方式。

提示

信息填写完整且勾选协议后，登录按钮才会变为可点的深蓝色（图 4、图 6、图 7）；如果按钮点不动，先确认是否漏勾下方协议。

1.2 注册账号

在账号登录页点击「注册账号」进入账号注册页（图 8）。按页面提示填写账号、密码并再次输入密码确认，勾选下方的用户隐私政策后点「注册」。

  • 两次输入的密码需要一致，密码框右侧眼睛图标可查看已输入内容。
  • 注册成功后返回登录页，用刚设置的账号与密码登录。
  • 不想单独注册时，也可直接在登录页用手机号 / 邮箱验证码登录，系统会自动创建账号。

第 2 章 首页与地图

首页是换电的主入口：定位决定能看到哪些站点，地图类型决定找「换电」还是「还电」，预约则锁定柜机与仓位。

2.1 首次进入与定位授权

从租车系统切换到换电系统后，未登录进入换电首页时（图 10），顶部为「请输入目的地」搜索条，中部为地图与站点气泡，右侧竖排三个浮动按钮（切换地图、回到当前定位、刷新），底部主按钮为「扫码换电」。

定位未开启时，地图上方出现横幅「定位服务未开启 / 开启后才能获取附近换电站点」并带「去开启」按钮（图 11）。点击后弹出「定位服务」说明弹窗，选择「去开启」会拉起系统定位授权（图 12）：

  • 允许：地图定位到当前位置并加载附近站点。
  • 不允许：不阻塞浏览，地图停在默认城市中心，可用搜索目的地手动查找站点。

2.2 地图类型与站点气泡

右侧第一个浮动按钮打开「切换地图」面板（图 17），三种地图用颜色区分：换电（绿色闪电）、还电（橙色电池）、门店（蓝色门店），选中项带蓝色描边。三种地图共用底部站点卡片，但展示的点位与筛选条件不同。

  • 换电地图（图 13、图 14）：气泡数字为该站点可换电池数量，数量多时显示「10+」；带「推荐」角标的为推荐站点；灰色气泡表示暂不可用（无可用满电电池）。
  • 还电地图（图 15、图 16）：只展示可归还电池的站点，气泡颜色为橙色，用于「手上还有电池要还」的场景。
  • 门店地图（图 17、图 18）：展示门店（含换电柜的门店），点击气泡弹出门店卡片，可进入门店详情查看换电 / 租车 / 售后等服务标签。

当用户存在未结束的换电 / 借电 / 还电流程时，首页顶部会出现「您有一个进行中的流程」+「立即前往」横幅（图 13），点击直接回到该流程页，避免重复开仓。

2.3 选中站点与预约

点击任意站点气泡后，页面顶部浮出站点横幅、底部弹出站点卡片：

  • 顶部横幅：站点名、地址、预约状态与倒计时（如「预约中 | 09分59秒」）、右侧「取消预约」。
  • 底部卡片：站点名与地址、替换站点用的关闭键、「可换电池 / 空仓」两个统计值、底部「扫码换电」+「预约换电」（预约后变为「取消预约」）。

已预约某个柜机时，其他柜机的「预约换电」按钮变为灰色不可点（图 21），避免同一账号占用多个仓位。已预约状态下点击「取消预约」会弹出二次确认（图 20）：「确定取消预约？取消预约后，10分钟内不可再次预约」，取消 / 确认两个按钮。

预约规则

预约默认保留 10 分钟（倒计时从预约成功开始），超时未到柜则自动释放并提示「预约已超时，可重新预约」；主动取消后 10 分钟内不可再次预约；同一时间只允许预约一个柜机。预约只锁定仓位，不产生费用，实际扣次以扫码换电成功为准。

提示

还电场景（图 23）不提供预约：因为还电只需要一个空仓，任一可用站点均可归还，预约会人为降低仓位周转率。

2.4 搜索目的地

点击首页顶部搜索条进入「搜索目的地」页。按使用状态分为五种界面：

  • 未开启定位（图 24）：提示当前无法获取位置并提供「去开启」，同时仍展示历史搜索。
  • 无历史搜索（图 25）：仅展示「附近换电站点」与「重新定位」。
  • 有历史搜索（图 26）：顶部「搜索历史」标签（可点选直接搜索），右上角垃圾桶清空历史；下方为「附近换电站点」列表，每项显示距离与「可借 / 可还」数量，点击进入站点详情。
  • 已输入（图 27）：输入关键字后实时联想地点与站点。
  • 输入无结果（图 28）：显示「没有找到相关地点」空态，输入框右侧清除键可一键清空重输。
提示

搜索历史保存在本地缓存，最多保留最近若干条；点击垃圾桶即清空，清空后页面回落为「无历史搜索」形态（图 25）。

2.5 门店详情

在门店地图点击门店气泡后进入「门店详情」（图 29、图 30）。页面上半部分为门店实景照片，下方信息卡依次为：

  • 门店名称、地址、服务标签（换电 / 租车 / 售后|维修 / 买车|电池）。
  • 营业时间（如 09:00–19:00）、电话拨号键、距离与导航入口。
  • 该门店下的换电柜卡片：柜编码、柜号（A01）、可换电池 / 空仓数量、「预约换电」按钮。

门店与换电站点的区别在于：门店是线下服务网点，可能同时提供租车、维修、售车服务；站点强调换电能力，一个门店可以放置多个换电柜。

第 3 章 站点详情与预约

站点详情是「查看柜位 → 锁定仓门」的页面；预约成功后首页与详情页都会出现倒计时，逾期自动释放。

3.1 换电站点详情

从地图站点卡片、搜索结果或附近站点列表进入「站点详情」。页面自上而下为：站点实景照片 → 站点信息卡 → 换电柜卡片列表（一个柜一张卡）。

  • 站点信息：站点名称、地址、营业时间（如 09:00–19:00）、电话拨号、距离与导航（如 1.2km）。
  • 换电柜卡片：柜编码、柜号（如 A01 号换电柜）、「可换电池 / 空仓」两个数字、「预约换电」按钮。
  • 未预约（图 31）：每个柜都有「预约换电」按钮，点击即锁定该柜的一个仓位。
  • 已预约（图 32）：被预约柜的按钮区替换为「预约中 | 09分59秒」与「取消预约」，其余柜的预约按钮置灰。
规则

多柜站点必须指定柜机：点「预约换电」时若未指明柜号，页面提示「请选择要预约的柜机」。可换电池为 0 的柜不允许预约；空仓为 0 只影响还电，不影响换电与借电。

3.2 导航与取消预约

点击站点信息卡右侧的距离 / 导航图标（图 33），会弹出地图应用选择：高德地图、百度地图、谷歌地图（按设备已安装应用展示）。选择后跳出 App 进行路线导航，返回后仍停留在站点详情，预约状态不丢失。

点击「取消预约」弹出二次确认（图 34）：标题「取消预约」，描述「确定取消预约？取消预约后，10分钟内不可再次预约」，按钮为「取消 / 确认」。确认后：

  • 预约横幅与倒计时移除，柜位释放给其他用户。
  • 该账号进入 10 分钟冷却期，期间所有柜机的「预约换电」均不可用。
  • 首页、站点详情、底部卡片三处的预约态同步清除。
注意

预约超时、主动取消、预约后成功换电，这三种情况都会结束预约态；其中主动取消后 10 分钟内不可再次预约（弹窗中已注明）。

第 4 章 扫码与使用条件

扫码是换电的起点。扫码后系统会先检查是否具备使用条件，再看可分配电池的电量，最后由你选择「借电」还是「换电」。

4.1 扫码与手动输入机柜编号

在首页点击「扫码换电」进入扫码页（图 35）。页面为全屏取景框，提示语「请将二维码对准取景框」，底部三个入口：手电筒（图 36，暗光环境补光）、键盘（手动输入机柜编号）、相册（从相册识别二维码）。左上角返回键退出扫码。

点击键盘图标进入「机柜编号」页（图 37、图 38）：按提示「请输入机柜编号」输入柜体上标注的编号，输入框右侧会实时显示已输入的字数。输入后「确定」由灰变蓝，点击即等同扫码成功；输入有误可清空重填。

扫码结果按固定顺序判定，命中任一条即中止并提示：

二维码无效›不支持跨运营商换电›设备已离线›距离过远无法操作
提示

「距离过远」由扫码时手机定位与柜机位置的距离判定，通常要求用户在柜机附近操作；室内信号漂移导致误判时，建议靠近柜机并重新定位后再扫。

4.2 使用前的条件检查

扫码成功后，系统会先确认是否具备使用条件。任一项不满足都会弹窗提示，按提示补全后回到扫码页重新扫码即可：

  • 未登录：直接拉起登录页，登录成功后回到原扫码流程。
  • 未实名（图 39）：弹窗「实名认证 / 请先完成实名认证后再使用换电服务」，按钮「取消 / 去认证」。
  • 未设置换电区域：在「我的 → 换电区域」新增并选中区域（见 10.5）。
  • 未缴押金（图 40）：弹窗「未缴纳押金 / 请先缴纳押金，方可使用换电服务」，按钮「取消 / 前往缴纳」；已免押用户跳过此项。
  • 未购套餐（图 41）：弹窗「未购买套餐 / 请您先购买套餐，再使用换电服务。」，按钮「取消 / 立即购买」。
  • 有进行中流程：不新开流程，直接回到未结束的流程页继续操作。

4.3 电量提示与操作选择

条件满足后，系统会检查可分配电池的电量。若电量偏低（低于 70%），先弹提示（图 42）：标题「电量偏低」，描述「可分配的电池电量偏低（<70%），继续使用可能会影响您的续航里程。」，按钮「取消 / 继续」。点「取消」则停留在扫码页，不会打开任何仓门。

随后按用户当前持有的电池数量决定操作类型（图 43）：

  • 持有 0 块：直接进入借电（2 步）。
  • 持有数量 达到上限（如 3 块）：直接进入换电（4 步）。
  • 介于两者之间：弹窗「选择操作」，描述「检测到您已持有 N 块电池（上限 M 块）」，按钮「借电 / 换电」，由用户选择。
规则

选择「换电」需要柜内同时存在可用空仓与满电仓；选择「借电」只需要满电仓。二者都会占用一次套餐次数（不限次套餐除外），失败不扣次。

第 5 章 换电流程（4 步）

换电＝放旧取新：打开空仓 → 放入旧电池 → 打开满电仓 → 取出新电池。每步都有进度、倒计时与独立失败态。

打开空仓›放入旧电池›打开满电仓›取出新电池

5.1 第 1 步 打开空仓

进入换电页后顶部为 4 步进度条，当前步高亮橙色，已完成的步显示为实心深色数字。第 1 步执行「空仓门打开中（x%）」（图 44），进度条随柜体返回的进度推进。

仓门打开后停止在待操作态（图 45）：「05号 ｜ 仓门已打开」，下方提示「请放入旧电池并关闭仓门 ｜ 60s」，倒计时从 60 秒开始，用于限制仓位长时间敞开。

若柜体回报开门失败（图 46）：显示「仓门打开失败」+「流程结束原因说明」，按钮「重试」回到扫码页（本流程结束、不扣次）。

5.2 第 2 步 放入旧电池

用户把旧电池放入已打开的仓位并关闭仓门，柜体检测到电池后自动进入第 3 步，无需在手机上点确认。60 秒倒计时内未检测到放入动作时：有网络则继续等待柜体推送，无网络则按「网络断开」处理（见 5.5）。

若柜体判定放入失败（图 47）：「旧电池放入失败」+ 原因说明，按钮「返回首页」。此时旧电池仍在用户手中，本次换电不扣次，可重新扫码再次尝试。

注意

旧电池必须与柜体匹配且状态可识别（未损坏、非他站锁定电池）。放入失败时不要反复强行推入，先取出电池检查仓位是否有异物，再重新扫码。

5.3 第 3 步 打开满电仓

第 3 步「满电仓门打开中（x%）」（图 48），成功后显示「A03号 ｜ 仓门已打开」与「请取走电池并关闭仓门 ｜ 60s」（图 49）。此处同样有 60 秒取电窗口，超时按网络状态处理。

满电仓打开失败（图 50）显示「仓门打开失败」+ 原因说明，按钮为「返回首页」。由于此时旧电池已被柜体收走，流程不能简单重试，需以记录为准联系客服处理。

5.4 第 4 步 取出新电池与完成

取出满电电池并关闭仓门，柜体确认后进入完成页（图 51）：「电池取出成功，换电完成」，点击「完成」回到首页。此时系统写入一条换电记录（站点、柜号、电池编号、取还时间），旧电池解绑、新电池绑定到当前账号。

未完成取电的两种失败形态：

  • 新电池取出失败（图 52）：柜体检测异常，按钮「返回首页」。
  • 未取出电池（图 53）：60 秒内未取走电池，按钮「重试」，可回到扫码页重新扫码取电。
规则

只有「换电完成」才写入换电记录并扣减套餐次数；任一环节失败或超时都不扣次。已打开的仓门必须先关闭，否则该仓位继续被占用，影响其他用户使用。

5.5 异常与网络中断

三个待操作环节（放入旧电池、取出新电池等）共用同一套超时逻辑：倒计时归零时先检测网络——

  • 有网络：不主动结束流程，继续等待柜体的推送结果（柜门可能仍开着，用户可继续操作）。
  • 无网络：弹出「网络断开」提示（图 54）：「网络连接已断开，请检查网络状况」，仅「确认」按钮，确认后回到首页，流程结束。

恢复网络后可重新扫码继续；若旧电池已被柜体收走，建议先在「我的 → 换电记录」确认本次是否已完成，再决定是否需要重新操作，避免重复换电。

第 6 章 借电流程（2 步）

借电＝只取电池、不放旧电池。适用于手上没有电池、需要临时多带一块满电电池的场景。

打开满电仓›取出电池

6.1 打开满电仓与取电

借电流程只有 2 步，顶部进度条显示「打开满电仓 → 取出电池」。第 1 步执行开仓，界面显示「满电仓门打开中（x%）」（图 55）；打开成功后提示「A01号 ｜ 仓门已打开」「请取走电池并关闭仓门 ｜ 60s」（图 56）。

开仓失败时显示「仓门打开失败」+ 原因说明，按钮为「重试」，点击回到扫码页重新开始（图 57）。

6.2 借电完成

取出电池并关闭仓门后进入完成页（图 58）：「电池取出成功，借电完成」，点「完成」回到首页。系统写入一条借电记录，状态为「使用中」，并把该电池绑定到当前账号——之后可在「我的 → 我的电池」查看电量、位置与使用时长。

规则

借电会占用套餐次数（不限次套餐除外），并使账号持有电池数 +1；达到持有上限后再次扫码只能走换电，不再询问「借电 / 换电」。

6.3 异常与网络中断

借电的 60 秒取电窗口同样按网络状态处理：有网络继续等待柜体推送，无网络则弹「网络断开」提示（图 59），确认后回首页，流程结束、不扣次。恢复网络后可重新扫码，仓门仍开着时优先取走电池并关门。

第 7 章 还电流程（2 步）

还电＝只归还电池。入口有两处：换电地图切到「还电」后扫码，或「我的电池 → 扫码还电」。

打开空仓›放入电池

7.1 打开空仓

还电顶部进度条为 2 步「打开空仓 → 放入电池」。第 1 步显示「空仓门打开中（x%）」（图 60），成功后提示仓号、门已打开，并给出 60 秒放入窗口（图 61）。

空仓打开失败（图 62）：「仓门打开失败」+ 原因说明，按钮「重试」回到扫码页。失败常见原因是该柜暂无可用空仓，可换一个站点或换电柜重试。

7.2 归还成功与放入失败

放入电池并关闭仓门，柜体检测通过后进入完成页（图 63）：「电池归还成功，还电完成」，点「完成」回到首页。此时系统写入还电记录，解除该电池与账号的绑定，并回收柜位。

若柜体判定放入失败（图 64）：显示「电池放入失败」+ 原因说明，按钮为「返回首页」。电池会退回给用户，不扣次，可换柜重试。

提示

还电成功后，这块电池会从「我的电池」中移除，本次归还信息可在「我的 → 换电记录」中查看（取电柜子、还电柜子、还电时间）。

7.3 异常与网络中断

放入窗口内断网时，弹出「网络断开」提示（图 65）：标题「网络断开」、描述「网络连接已断开，请检查网络状况」，仅「确认」按钮，确认后回首页。恢复网络后可重新扫码；若电池已被柜体收下，先在换电记录中确认本次是否已完成，不要重复归还。

第 8 章 套餐购买与我的套餐

套餐是扫码换电的前置条件：先选区域与套餐，支付成功后套餐生效，再回到首页扫码。

8.1 套餐列表

底部「套餐」tab 进入「购买套餐」（图 66）。页面顶部为当前区域（运营商名称或城市）+「我的套餐 / 我的卡包」入口，下方为套餐卡片列表，可继续上滑（图 67）。

  • 卡片上显示：套餐名称、现价（红色）、原价（灰色删除线）、有效期（如「有效期：30 天」）。
  • 点击卡片或「查看详情」打开套餐详情面板（见 8.2）。
  • 未登录（图 68）：顶部深蓝横幅「您还未登录，点我快速登录」+「去登录」，列表区显示「暂无相关数据」。
  • 未设置换电区域（图 69）：横幅「您尚未设置换电区域」+「去设置」，不展示套餐列表。
  • 区域无在售套餐（图 70）：空态「暂无相关数据」。

8.2 套餐详情与支付

点击套餐卡片底部弹出「套餐详情」面板：标题右侧关闭键，面板内为套餐名称、参数表（有效期 / 换电次数 / 可借电池）、「套餐描述」，底部左侧为应付金额、右侧「立即支付」。

  • 不限次套餐（图 71）：「换电次数」显示「不限次」。
  • 限次套餐（图 72）：显示具体次数（如「30 次」）与可借电池数（如「10 块」）。
  • 描述较长时可上滑查看完整内容（图 73），支付按钮固定底部不随内容滚动。
  • 未缴押金（图 74）：点击立即支付弹窗「未缴纳押金 / 请您先缴纳押金，再购买套餐」，按钮「取消 / 前往缴纳」。

支付成功后生成一笔「换电套餐」订单（状态「已支付」），套餐立即生效并出现在「我的套餐」中；支付失败或超时则订单停留在「待支付」，可在订单详情重新支付。

8.3 我的套餐

从「我的 → 我的套餐」或套餐页右上「我的套餐」进入。每张卡片显示：套餐名称、状态标签「生效中」（绿色）、剩余次数、可借电池、有效期、有效期至（精确到时分秒）（图 75）。

  • 右上角「已失效」进入失效套餐列表（图 76）：标题「失效套餐」，卡片标签为「已失效」。
  • 失效套餐为空（图 77）：「暂无失效套餐」。
  • 无任何套餐（图 78）：空态「暂无套餐」，可返回套餐页购买。
规则

套餐到期后自动失效，不再出现在生效列表，只进「已失效」；未用完的次数随失效一起作废。同一账号可同时拥有多个生效套餐，扫码换电时自动使用其中可用的套餐。

第 9 章 订单管理

换电套餐订单的查询、支付、取消与退款：状态从「待支付」开始，支付成功转「已支付」，退款则经「退款中」到「已退款」。

待支付›已支付›退款中›已退款

9.1 订单入口与列表

「我的 → 我的订单」先进入订单类型页（图 79），当前仅「换电套餐」一个分类，点击进入订单列表；右上角为订单插画空态装饰，无操作。

列表页（图 80）顶部为状态 tab：全部 / 待支付 / 已支付 / 退款中 / 已退款，每个 tab 内按创建时间倒序展示订单卡片：

  • 卡片第一行：套餐名称 + 右侧状态标签（待支付橙、已支付绿、退款中 / 已退款 / 已取消 灰）。
  • 参数区：有效期、换电次数、可借电池。
  • 底行：创建时间 + 订单金额（如 Rp 345.677.566）。
  • 无数据（图 81）：空态「暂无订单」。

9.2 订单详情与支付

点击订单卡片进入「订单详情」。待支付订单顶部有红色倒计时条：「剩余29分59秒，超时未支付，订单将自动取消」（图 82），下方依次为套餐信息卡、订单信息卡（订单编号、创建时间、订单金额 / 实付金额、支付时间）、底部「取消订单」与「立即支付」。

点击「取消订单」弹出确认（图 83）：「取消订单 / 确定取消该订单？取消后不可恢复」，按钮「取消 / 确定」；确认后订单转为「已取消」，不可恢复。

支付成功后订单转「已支付」：套餐仍在有效期内显示 生效中（图 84），套餐到期后同一订单显示 已失效（图 85），两种状态都不影响订单记录本身。

规则

待支付订单需在 30 分钟内完成付款，超时会自动取消且不扣款；已支付订单不能取消，只能申请退款。联系客服时提供订单详情里的订单编号，可快速定位这笔订单。

9.3 退款与取消

已支付订单申请退款后进入「退款中」（图 86），此时订单不可再次操作，页面展示退款信息（申请时间、退款金额、退款渠道）；退款到账后转为「已退款」（图 87），状态标签为灰色，金额不再高亮。

未支付且已超过有效期的订单显示「已取消」（图 88）：仅保留套餐与金额信息，无操作按钮。已退款与已取消订单均保留在「全部」中，可按对应 tab 过滤。

注意

退款中的订单不可再次申请退款；审核期间该套餐不再参与扣次，避免出现「已退款仍可用」。退款失败会在订单详情给出原因，可重新发起。

第 10 章 我的

「我的」是换电业务的个人中心：订单、套餐、电池、换电记录、押金、换电区域六个入口，外加个人信息与系统设置。

10.1 我的页与入口

底部 tab「我的」进入个人中心（图 89）。页面结构自上而下：

  • 头部：头像、昵称、手机号（点击进入个人信息），右上角齿轮进入系统设置。
  • 系统卡：「换电系统」图标 + 名称 + 右侧「切换」，点击进入「切换系统」页。
  • 功能列表：我的订单、我的套餐、我的电池、换电记录、我的押金、换电区域，每项右侧有箭头。
  • 底部 tab：首页 / 套餐 / 我的，当前 tab 高亮。

10.2 我的电池

「我的电池」列出当前账号绑定 / 持有的电池（图 90），每张卡片显示电池编号、电池位置、绑定时间；没有电池时显示空态「暂无电池」（图 91）。

点击电池进入电池详情（图 104、图 105、图 106）：

  • 顶部仪表盘：剩余电量百分比（0–100 分档，图 92–图 103 为各电量区间的仪表形态）。
  • 三个核心指标：剩余电量（%）、剩余里程（约 x km）、使用时长（x 分钟）。
  • 电池编号、电池位置、绑定时间。
  • 两张地图卡：「当前位置」显示电池所在站点，「轨迹」显示历史移动路线；底部红字「扫码还电」直接进入还电扫码。

剩余里程与使用时长由电池电量与单车功耗估算，仅作参考；电量越低仪表越偏告警色（0% 为红色告警态，100% 为满格态）。电池与账号在借电或换电成功时绑定，还电成功后解绑。

10.3 换电记录

「换电记录」按时间倒序展示换电 / 借电 / 还电记录（图 107）。每条记录包含：订单编号、电池编号、取电柜子、还电柜子、取电时间、还电时间，右侧复制图标可一键复制该项内容，复制成功提示「复制成功」。

只借电未还电时，还电柜子与还电时间为空，表示电池仍在用户手中。无记录时显示「暂无记录」（图 108）。

10.4 我的押金

押金按运营商收取，一个账号可对应多个运营商的押金。押金详情页顶部为深色押金卡：押金名称（换电押金）、状态标签、运营商、金额。

  • 未缴纳（图 109）：标签「未缴纳」，展示「押金须知」四条——先缴后享、不可抵扣换电费、随时可退、损失赔偿；底部「立即支付」。
  • 已免押（图 110）：金额位置显示「已免押」，无需缴纳即可使用换电服务。
  • 已缴纳（图 111）：标签「已缴纳」，须知切换为「退押须知」两条——随时可退、损失赔偿；底部「申请退款」。
  • 退款中：按钮变为灰色「退款审核中」，不可重复申请。

点击「申请退款」弹出提示（图 112）：「温馨提示 / 您当前持有生效中的换电套餐，押金退还后，换电权益将暂停。确认申请退还押金吗？」，按钮「我再想想 / 申请退款」。确认后进入审核，成功时提示（图 113）：「申请成功 / 押金会在 7 个工作日内原路退回至您原支付账户，请您耐心等候。/ 知道了」。

规则

押金只作为设备保障，不可抵扣换电费用；退还后换电权益立即暂停，需重新缴纳才能继续使用。押金金额由所在区域的运营商配置，以页面显示的金额为准。

10.5 换电区域

「换电区域」管理账号可用的运营商区域（图 114）。列表每行为运营商名称 + 所在省市区，当前生效区域右侧带橙色勾选；底部「新增」按钮添加区域，无区域时显示空态「暂无换电区域 / 请点击下方「新增」添加」（图 115）。

点击「新增」进入四级级联选择，面包屑统一显示「请选择」：

国家›省份 / 地区›城市›运营商
  • 国家列表（图 116）：选择服务所在国家，当前为中国。
  • 省份 / 地区（图 117）：如四川省。
  • 城市（图 118）：如成都市；该城市未开通时提示「该城市暂未开通换电服务」。
  • 运营商（图 119）：显示「城市 + 运营商」名称；该城市运营商已全部添加时提示「该城市运营商已全部添加」。

选定运营商后回到区域列表，新区域加入并可直接点选切换为当前区域。

第 11 章 个人信息与账号安全

从「我的」点头像进入个人信息，可维护昵称、账号、手机号、邮箱、密码与实名信息；系统设置负责语言、系统与退出登录。

11.1 个人信息总览

个人信息页为纯列表结构（图 120、图 121），每行右侧显示当前值并带箭头：

  • 头像：点击更换头像（从相册 / 拍照）。
  • 账号：登录账号，可修改，修改后需用新账号登录。
  • 昵称：展示昵称，如「小迪」。
  • 手机号 / 邮箱地址：未绑定显示灰色「未绑定」，已绑定显示脱敏后的号码 / 邮箱。
  • 密码管理：未设置密码时显示「设置密码」，已设置显示「修改密码」。
  • 实名信息：「未实名」为灰色，「已实名」为深色。
  • 注销账号：页面底部独立按钮，二次确认后清除数据且不可恢复。

11.2 绑定与更换手机号

未绑定手机号时点击「手机号 → 未绑定」进入「绑定手机号」（图 122）：区号选择 + 手机号输入 + 验证码（右侧「获取验证码」60 秒倒计时）+ 底部「绑定」。填写完整后按钮变为可点（图 123）。

已绑定后同一行进入「更换手机号」（图 124、图 125）：页面顶部显示「当前已绑定：+86 17654654333」，下方输入新手机号与验证码，确认后原号码解绑、新号码生效，提示「手机号替换成功」。

规则

手机号用于登录与找回密码，更换时需先通过新号码的验证码验证。未绑定手机号不影响换电，但无法使用手机号验证码登录。

11.3 绑定与更换邮箱

邮箱流程与手机号一致：未绑定时进入「绑定邮箱」（图 126、图 127），输入邮箱地址 + 验证码 + 「绑定」；已绑定时进入「更换邮箱」（图 128、图 129），顶部显示「当前已绑定：xxx@xxx.com」，验证新邮箱后替换。

邮箱可用于接收订单 / 退款通知，也可作为登录方式（邮箱验证码 / 密码登录）。邮箱不要求唯一，但同一账号只保留一个。

11.4 修改密码

密码管理入口按是否已设置密码显示「设置密码 / 修改密码」。修改密码分两步：先验证身份，再设置新密码。

手机号 / 邮箱验证›重置密码
  • 身份验证：默认「手机号验证」（图 130），展示当前手机号与验证码输入框，底部可切到「邮箱验证」（图 131）。获取并填写验证码后点「下一步」。
  • 重置密码（图 132、图 133）：标题「重置密码」，两个输入框分别输入新密码与确认新密码，右侧眼睛图标可查看已输入内容；两次一致后「确认」可点，成功提示「密码已更新」。
规则

新密码设置成功后旧密码立即失效，其他已登录的设备需用新密码重新登录。

11.5 实名认证

未实名时点击「实名信息 → 未实名」进入「新增实名信息」（图 134），需要填写或上传三项：

  • 姓名：与证件一致的本人姓名。
  • 身份证：证件号码。
  • 身份证照片：点击相机框上传（图 136），最多 2 张，按提示「请上传清晰证件照，避免反光」拍摄；上传后可预览、可删除重传（图 137）。

漏填或漏传时点「保存」会在对应项提示缺少的内容（图 138）；补齐后提交，个人信息页的实名状态即变为「已实名」。

已实名后进入「实名详情」（图 139、图 140）：姓名、脱敏身份证号（如 33********************）、身份证照片，底部「编辑」可修改并重新提交。

注意

实名是扫码换电的前提条件之一（见 4.2），未实名时扫码会被拦截；实名信息与账号一一对应，修改后需要重新提交审核。

11.6 系统设置与退出登录

「我的」右上角齿轮进入「系统设置」（图 141）。页面分「通用设置」一组与底部退出按钮：

  • 切换语言：右侧显示当前语言（如「简体中文」），点击进入语言列表。
  • 切换系统：右侧显示当前系统（如「换电系统」），点击进入「切换系统」页（见第 12 章）。
  • 当前版本：只读展示，如 V1.21，用于客诉定位。
  • 退出登录：底部独立按钮，点击弹出确认（图 142）：「退出登录 / 确定要退出当前账号吗？退出后需重新登录。」，确认后清除登录态并回到登录页。
提示

退出登录只清除本机的登录态，不会删除订单、套餐、押金与换电记录；重新登录后数据原样恢复。

第 12 章 切换系统

App 冷启动进入租车系统；要使用换电，需要先切换到换电系统。两套系统共用同一账号，切换不用重新登录。

12.1 切换到换电系统

App 冷启动固定进入租车系统，不会先弹出切换页。进入换电系统需要主动切换，两处入口都能打开「切换系统」页（图 143）：

  • 「我的」页顶部系统卡右侧「切换」。
  • 「我的 → 系统设置 → 切换系统」。

在「切换系统」页点击「换电系统」卡片（或卡片内「进入系统」），即进入换电首页。切换只改变当前使用的业务模块：换电系统的底部 tab 为「首页 / 套餐 / 我的」，首页是换电地图；账号、登录状态、语言与个人信息在两套系统间共用，切换后不会退出登录。

提示

切回租车系统的方式相同：在换电系统「我的」页点顶部系统卡右侧「切换」，选择租车系统即可。两套系统的「我的」页菜单不同，认准底部 tab 与菜单项即可判断当前在哪套系统。

第 13 章 常见问题

按用户最常遇到的拦截、失败与状态疑问整理，可直接用于客服话术。

Q1　扫码后一直提示「未缴纳押金 / 未购买套餐」，怎么排查？

扫码前系统会确认几项条件，按提示逐项检查即可：是否已登录、实名是否为「已实名」（我的 → 个人信息）、「我的 → 换电区域」是否已添加并选中区域、押金是否为「已缴纳 / 已免押」（我的 → 我的押金）、是否有「生效中」的套餐（我的 → 我的套餐）。补全任一项后回到扫码页重新扫码。

Q2　预约的柜机迟到会怎样？取消后为什么不能马上再约？

预约保留 10 分钟，倒计时结束会自动释放，并提示「预约已超时，可重新预约」；主动取消后 10 分钟内所有柜机都不可再预约，这是为了避免反复占位。

Q3　提示「电量偏低（<70%）」还能换吗？

可以。该提示只是告知当前可分配电池电量不高，可能影响续航；点「继续」照常进入换电 / 借电，点「取消」则停留在扫码页、不开仓、不扣次。

Q4　仓门打不开 / 放入失败 / 取出失败，会扣套餐次数吗？

不会。只有走到「换电完成 / 借电完成 / 还电完成」才写记录并扣次；打开失败可「重试」回扫码页，旧电池放入失败与新电池取出失败按页面按钮返回首页，均不扣次。

Q5　流程进行中手机断网了怎么办？

倒计时结束时若断网，会弹「网络断开」提示并回首页，流程结束、不扣次。恢复网络后重新扫码即可；如果旧电池已被柜体收走而新电池未取出，以换电记录为准联系客服处理，避免重复操作。

Q6　为什么首页地图上的站点是灰色的？

灰色气泡表示该站点当前没有可用满电电池（或暂不可用），不可换电；此时切到「还电地图」仍可归还电池。气泡上的数字是可用满电电池数量，「10+」表示 10 块以上。

Q7　押金退款多久到账？退款后还能换电吗？

申请成功后提示「押金会在 7 个工作日内原路退回至您原支付账户」。退款审核期间按钮显示「退款审核中」；押金退还后换电权益立即暂停，需重新缴纳或重新获得免押资格才能继续使用。

Q8　套餐买了没生效 / 订单一直显示待支付？

套餐以订单「已支付」为生效条件。待支付订单有 30 分钟倒计时，超时自动取消；在订单详情点「立即支付」完成付款后，套餐进入「我的套餐」并显示「生效中」。若已扣款但订单仍显示待支付，保存订单详情里的订单编号联系客服核对。

Q9　同一账号能同时有多个套餐 / 多个换电区域吗？

可以。套餐可叠加，扫码换电时会自动使用其中可用的套餐；换电区域可以添加多个，但同一时刻只有一个生效区域，首页、套餐页与站点列表都按当前生效区域显示。

Q10　换电记录里的「还电柜子 / 还电时间」为什么是空的？

只借电未还电时，电池仍在用户手中，还电柜子与还电时间为空，记录状态为「使用中」。完成还电后该条记录补齐还电信息，并解除电池与账号的绑定。
